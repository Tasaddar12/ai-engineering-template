# ADR-005: Owned assets and adapter boundaries

Status: accepted for foundation, 2026-09-05.

## Context

A framework upgrade must not overwrite project knowledge.

## Decision

Hash manifest with framework-owned assets versus project-owned seeds; three-way upgrades; injected Git/agent/delivery ports.

## Alternatives

Whole-template replacement risks data loss; coupling to a hosted agent API hinders local tests.

## Consequences

Contract ownership and migration tests needed before parallel consumers.

## Reversibility

Add providers or asset versions without redefining project content ownership.
