# ADR-002: Plan-local records and single control writer

Status: accepted for foundation, 2026-09-05.

## Context

Parallel worktrees must not race on shared task files.

## Decision

Each plan is a complete bundle beneath `.ai/plans/{current,completed,archived}/PLAN-NNN/`. It owns its specification, graph, local task IDs, commands, reviews, evidence and history. Tasks use plan-local `{current,completed,archived}` directories plus explicit status fields. A future coordinator remains the single canonical state writer on the retained `ai/state` branch.

## Alternatives

Global task/graph/spec directories obscure ownership and prevent safe local ID reuse. Status-only files hide lifecycle navigation. Task-owned shared state causes conflicts; independent SQLite truth is not clone-visible.

## Consequences

References resolve within a plan bundle, while shared policy, decisions and research remain compact. Lifecycle moves update the registry and explicit status together. State branch must be fetched/published for cross-host resume; OS-local single-coordinator support initially.

## Reversibility

Migrate event store with compatibility migration; never silently swap authority.
