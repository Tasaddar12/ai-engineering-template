# Initialize project context

1. Use [onboard](../commands/onboard.md) to inspect an existing project or draft
   adoption decisions. Consult [ADOPTING](../../docs/ADOPTING.md) for copying.
2. Return the [decision summary](../templates/decision-summary.md); apply
   [action-approved](../gates/action-approved.md) before the proposed changes.
3. For authorized adoption publication, use [onboard-pr](../commands/onboard-pr.md).

Outcome: known project context, clear fact owners and named unresolved questions.
