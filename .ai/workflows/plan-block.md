# Record a real blocker

## Purpose

Expose a decision that genuinely prevents part of the approved work while
continuing independent tasks.

## Inputs

Selected PLAN, unanswered question, evidence and a recommended answer.

## Gates

Apply [action-approved](../gates/action-approved.md) to any new scope; an existing assignment permits recording
its blocker.

## Steps

1. Check that the issue is not ordinary investigation, a revisable plan, an
   evidenced stale document or a routine implementation choice.
2. State the exact question, recommendation, owner and resume condition in the
   plan.
3. Move to blocked only if the plan cannot otherwise proceed; record its return
   stage in the decision section, not duplicate stage metadata.
4. Update STATE with a link and journal the event.
5. Continue approved work that does not depend on the answer and return one
   concise decision.

## Output and handoff

A visible blocker with a single-reply route forward.

## Stop conditions

Do not turn uncertainty affecting one task into a global stop.
