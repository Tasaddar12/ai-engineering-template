# ADR-001: Flat local Python tools and JSON contracts

Status: accepted for foundation, 2026-09-05.

## Context

A fresh agent needs deterministic, portable, inspectable state.

## Decision

Python 3.11+, directly runnable modules under `src/`, JSON Schema 2020-12 and JSON records; Markdown rationale. No `src/ai_engineering/` or `src/scripts/` wrapper layer.

## Alternatives

Bash scripts are poorly portable; YAML adds parsing ambiguity; a database service is premature.

## Consequences

More explicit JSON; direct scripts remain easy to clone and run. Future YAML input may normalize to JSON.

## Reversibility

Add parser adapters or storage ports without changing artifact identity.
