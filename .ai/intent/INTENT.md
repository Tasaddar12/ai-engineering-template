# Project intent

## Outcome

Keep a small, understandable set of project contracts that separates current facts,
future plans, decision rationale and day-to-day coordination.

## Users

The project owner and agents working under the owner's explicit direction.

## Boundaries

Use the requested `.ai` layout, flat templates, a few clear agents and basic workflows.
Capture reports and obtain a user decision before acting. Keep one owner per fact.

## Exclusions

This draft does not implement a Python framework, automatic agents, executable hooks,
provider integrations or CI. It does not authorize merging the draft branch.
