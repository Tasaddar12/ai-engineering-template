# ADR-004: Two reviews and bounded recovery

Status: accepted for foundation, 2026-09-05.

## Context

Correct code may still violate architecture; decomposition failures should self-repair.

## Decision

Independent R1/R2 invocations, higher configured capability, exact fingerprints, structured recovery with lineage-wide budgets.

## Alternatives

One reviewer misses different failure modes; unlimited retries create runaway loops.

## Consequences

No default production provider; setup needs explicit supported profiles; exhausted budgets pause.

## Reversibility

Change budget/profile policy explicitly; preserve historical review provenance.
