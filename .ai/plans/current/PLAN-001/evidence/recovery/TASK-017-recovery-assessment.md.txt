private state restoration. `request.model_profile` is the **policy** name.
`ProjectSettings.configured_model` (`src/config.py:620`) resolves that name through
`AgentModels.provider_profile_for_policy` (`:536`) to a **provider** profile. The
two names need not be equal. Initial dispatch already follows the accepted mapping;
`_expected_model` deliberately retains the requested policy name in ModelIdentity,
while `_FakeEffect.configured_model` retains the resolved provider name and effort.

imports no candidate test helpers, changes only copied fixture configuration, and
uses separate interpreter processes. Both provider catalogs receive an
`implementation_custom` alias with the same existing implementation model/rank/effort;
the policy profile `implementation` selects that alias. Fake capabilities use the
active provider's actual decoded profiles. This is an admitted configuration, not a
synthetic invalid-settings counterexample.
