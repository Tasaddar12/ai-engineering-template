# Draft or revise a plan

Input: a linked intake report and a user instruction to plan.

1. Read intent, current specs and relevant decisions.
2. Fill templates/plan.md in plans/backlog with scope, a small checklist, acceptance,
   affected specs, risks and validation to perform at the end.
3. For a contract change, include a proposed AMD and its affected owner.
4. Move a proposal being presented to plans/review with review_type: proposal.
5. Return templates/decision-summary.md and wait for a decision on that proposal.

Output: a reviewable plan. Acceptance can return it to backlog; execution requires
an explicit instruction to execute the identified scope. Alterations reopen the report.
