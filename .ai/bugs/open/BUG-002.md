# BUG-002 — File-only assignment scopes

The current Codex adapter requires existing directory write roots and explicitly rejects file-only scopes. Add a supported exact-file mechanism in a later pass without widening write access to a parent directory. Until then, decomposition must use bounded existing directory scopes. No platform probes were run for this implementation.
