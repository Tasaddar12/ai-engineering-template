# Pilot PLAN a

## Acceptance

Create _pilot/a.py with increment(n) returning n + 1 for integer inputs. Add _pilot/test_a.py using unittest covering 0, 1, -2 and 20.

Inputs are integers; runtime type validation is not required. Use Python standard library only. _pilot is a namespace package; do not add a shared __init__.py. Tests import from _pilot.a, _pilot.b or _pilot.c. No contract or documentation change is required. Do not edit the PLAN. Run python -B -m unittest discover -s _pilot -v.
