# ADR-002: Stable records and single control writer

Status: accepted for foundation, 2026-09-05.

## Context

Parallel worktrees must not race on shared task files.

## Decision

Stable ID paths with status fields; coordinator-only writes on retained ai/state branch; local journal plus committed checkpoints.

## Alternatives

Moving files by status breaks references; task-owned shared state causes conflicts; independent SQLite truth is not clone-visible.

## Consequences

State branch must be fetched/published for cross-host resume; OS-local single-coordinator support initially.

## Reversibility

Migrate event store with compatibility migration; never silently swap authority.
