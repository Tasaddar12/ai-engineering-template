# Run configured regression checks

Read the complete immutable prior-suite discovery evidence from regression-gate.md. Require a cited mapping from every prior requirement/suite to the actual configured check IDs and input set. Missing verification files or a missing configured check leaves coverage pending; neither is a zero-suite pass. Run `engineer_run query verification.run-checks` from the integrated session revision when execution is authorized. The configured checks own argv and per-command timeouts; do not sniff a test command, normalize an invented command, or replace coverage with a successful empty runner.

Reuse only passing receipts whose input fingerprints are current. Retain command IDs, exit codes, timeouts, bounded output tails, origin phase coverage and the checked revision in the joined evidence. A timed-out runner halts dependent verification; never silently continue or call it a passed regression gate. A user-deferred run remains pending. Route demonstrated failures through the bounded isolated correction procedure and rerun invalidated checks after integration.

Use `engineer_run query verification.run-checks --checks ID...` only when the explicit selection still covers the complete required prior-phase mapping; otherwise run the full configured set. Take no phase positional argument. `verification.check-status` inspects current receipts without executing commands; it does not replace absent coverage or an unexecuted required test. Record genuine not-applicable with its roadmap evidence separately from passed, failed, timed-out and user-deferred pending.
