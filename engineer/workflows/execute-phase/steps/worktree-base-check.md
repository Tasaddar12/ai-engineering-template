# Fork-base mismatch

The executor's complete branch guard compares its assigned checkout and captured base before source changes. An exit 42 is a blocked plan with the actual expected and observed identities recorded. Preserve the worktree and its commits for inspection. Continue independent plans only after the failed worker has stopped. Re-attempt authorized recovery in a fresh isolated checkout from the recorded handoff; never change the isolation mode or ignore the base mismatch to make progress.
