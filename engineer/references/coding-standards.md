# Task-scoped coding standards

Before planning, implementing, fixing, investigating, verifying or reviewing code, read the
[standards index](../standards/README.md). Select and read only the files matching
the task's language, framework and design concerns before doing that work.
For broad documents, read the matching sections and examples; unrelated sections
are not required reading.
Standards for unrelated languages or topics are not required reading.

Apply the selected references within the assigned scope and project instructions.
If coverage is missing or conflicts with an explicit project decision, report the
gap or conflict instead of inventing a standard. These files are references, not
skills; do not register or invoke them as skills.
