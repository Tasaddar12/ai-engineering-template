# Agent adaptation contract

Adapt the copied upstream role body directly. Preserve complete methods, examples and return protocols unless a named reconciliation row replaces a conflicting behavior. Do not rebuild a role from a summary or reuse retired local workflow files as its base.

## Role ownership

Read `agents/README.md`, the assigned role, consuming workflow and required references. Keep facts in their owning layer: commands name procedures, workflows route steps, roles bound work, templates define complete artifacts, references hold reusable methods and the runtime owns structured planning mutations.

## Supported hosts

Only Claude and Codex adapters are supported. Resolve exact final roles and model/effort using runtime interfaces; omit inherited settings and pass resolved values inline on actual host dispatch. Do not add another AI host, generic fallback role, model profile router or unverified native integration.

## Assignment fidelity

Preserve repository/branch/revision verification, exact path ownership, declared deletions/resources, read_first, checks argv, source/result identity and pending human decisions. A write worker commits owned changes and required summary; a read-only role returns its cited packet without a completion commit. The coordinator owns lifecycle, integration, shared records and publication.

## Planning and evidence

Require complete acceptance, documentation, checks and issue_refs metadata in current plans. Workers cannot mutate shared PLAN/STATE/ROADMAP/REQUIREMENTS structures to declare their own success. Preserve TDD RED formats and semantic checks, v4 digest, behavioral verification, human UAT and resolved_by history. Never invent a passing check or waive acceptance through a mode flag.

## Return and consumption

Identify whether a consumer uses a sentinel, artifact+query or structured-return. Preserve exact active marker case where it is consumed; presentation markers do not prove completion. Update producer and consumer together when a contract changes. Return completed, remaining, dirty paths, checks and next bounded action on partial work.

## Review

Compare the changed role with its copied upstream body and named rows. Confirm full methods/examples remain, old runtime calls are replaced by actual supported interfaces, ownership gates remain explicit, and every required output has a real consumer. Do not describe unexecuted review or checks as passed.
