# Phases

Create stable `NN-slug/` directories through [phase](../../commands/phase.md).
Start with CONTEXT, add research when needed, prepare component instructions,
execute ready components and collect summaries, verification and applicable UAT.

See [the workflow guide](../../docs/PHASE-WORKFLOW.md) for the full operation.
[ROADMAP](../ROADMAP.md) indexes phases; [progress](../../commands/progress.md)
reports observed progress. Do not move folders to represent status.

Create phases only for this project's agreed outcomes; instructional examples
do not establish project scope or delivery history.

See [phase artifacts](../../engineer/references/phase-artifacts.md) for each record's required contents, author and consumer.
