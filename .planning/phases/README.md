# Phases

Create stable `NN-slug/` directories through [phase-new](../commands/phase-new.md).
Start with CONTEXT, add research when needed, prepare component instructions,
execute ready components and collect summaries, verification and applicable UAT.

See [phase artifacts](../references/phase-artifacts.md) for each file's owner and
[the workflow guide](../../docs/PHASE-WORKFLOW.md) for the full operation.
[ROADMAP](../ROADMAP.md) indexes phases; [phase-status](../commands/phase-status.md)
reports observed progress. Do not move folders to represent status.

This reusable template does not seed fictional project phases.
